04 / QUESTIONS

关于接入与使用

把开发者关心的问题
讲清楚

如何接入现有 Unity 项目？+

规划通过 Unity 项目包与保护配置接入，将加固融入原有构建流程。根据项目的资源加载方式与关键代码选择适配范围，原始资产和业务源码保持独立管理。

加固发生在构建的哪个阶段？+

加固集成在构建过程中：资产在资源处理阶段保护，逻辑在相应代码处理阶段变换，必要的运行组件随应用一起构建。具体接入点随 Unity 版本、脚本后端和平台适配。

玩家的运行体验会改变吗？+

目标是玩家照常启动与游玩，无需额外操作，功能、资源品质、存档和协议保持一致。解密与校验的性能开销单独实测，不把“体验零干扰”等同于零计算开销。

iOS、Android 和 Windows 都能使用吗？+

三个平台是产品目标，具体支持以发布版本的兼容性结果为准。首个研究环境为 Windows x64 与 IL2CPP；官网的多平台流水线展示目标流程。

如何确认加固后的防护效果？+

围绕资产提取、内存修改和逻辑还原直接验证，对比同一游戏加固前后的结果，并核对正常功能、资源与性能。REA 类工具用于逆向分析验证，具体测试能力按工具和任务分别记录。

现在可以获取哪些内容？+

目前开放产品设计、接入思路、技术方案与演练方法。项目处于设计与研究阶段，可安装组件和实际防护结果将在版本验证完成后发布。
