# kingsSafe 第一版计划

v0.1 先交付资源保护的完整链条，v0.2 再交付关键数据内存保护。实现前先确定目标、威胁模型、候选技术和评测标准；以下为产品任务，尚未通过验收。2026 年 10 月 30 日的[隔离构建机制探针](build-hardening-feasibility.md)不等于首版实现。

## v0.1 交付包

| 工作面 | 交付 |
| --- | --- |
| 设计 | 资源覆盖清单、格式、密钥与缓存决策、失败语义 |
| 工具 | 本地 AssetBundle 打包保护与发行清单 |
| 运行 | 必要的 Runtime、Stream 加载与释放 |
| 样本 | 模型、贴图、音频、动画、Prefab、依赖和场景加载 |
| 验证 | 原包与保护包对照、资源等价、故障与缓存测试 |
| 攻防 | 通用工具与已知源码定向任务、REA 记录 |
| 性能 | 固定设备上的启动、加载、帧时、GC 和内存报告 |
| 协作 | 复现说明、已知绕过、支持矩阵和回归入口 |

v0.1 首先支持明确清单内的本地 AssetBundle。Addressables provider 是接入扩展，固定包版本后单独验收。直接 AssetBundle 样本通过不能宣称所有 Unity 项目和资源路径零改动接入。

## 零业务改动产品门槛

产品验收要求只引入插件、继续原 Build，不手改业务源码、加载调用、字段类型、场景或构建脚本。加载门面与显式保护类型可用于内部机制研究，但不能代替自动接入。版本支持范围、自动适配覆盖与未支持项必须可查。

内存保护同步纳入窥探探测与自终止研究，按[专项调研](memory-observation-research.md)执行 P0 到 P2 后再决定具体路线。研究中继续保留资源优先交付顺序，不将探测原型当作全部三项防护已经实现。

## M0 固定设计与实验条件

锁定 Unity 6.3 LTS 完整补丁、Windows x64 IL2CPP 工具链、候选密码库、设备与样本。形成资源清单、格式草案、密钥交付决策、缓存策略和加载入口说明。

在实现前冻结[评测与验证标准](validation.md)中的任务、工具版本、阳性对照、预算、采样方法和判定。确定最低目标设备与主流设备，记录全部性能预算；没有预算不进行发布性能判定。

退出条件：每个目标都有成功与失败证据定义，密钥和原始资源来源合法，未支持路径明确，可复现实验输入齐备。

## M1 验证资源保护机制

验证认证加密、独立块读写、错误数据处理和容器往返；随后在实际 IL2CPP Player 中接通加载。运行时与构建侧不能仅在桌面测试库中自洽，必须通过目标 Player 验证。

退出条件：解密 Bundle 与原 Bundle 字节相同；损坏、错误密钥、重排、截断与混包被拒绝；读取边界、异常长度、线程与生命周期实验通过。

## M2 完成加载与资源链条

覆盖同步和异步加载、依赖、取消、卸载、重复加载及引用释放。检查磁盘临时目录、缓存、错误日志和发行包，不泄漏完整明文 Bundle 或研发密钥。AssetBundle 原加载门面和 Addressables 适配分别记录。

退出条件：所有声明支持样本通过功能与资源等价验收；原业务和资产未损坏，失败不自动退回明文；密钥交付与运行时暴露边界有实测记录。

## M3 完成攻防和性能报告

运行通用拆包、已知源码定向处理和运行时提取任务，同时完成最低配置和主流设备的独立性能测量。对照隔离容器、运行组件和逻辑混淆的成本。所有代码与工具版本、资源摘要和复现步骤固定。

退出条件：G1/G2 达到预定标准，功能和资源无损，性能满足预先预算，定向绕过与限制完整披露。若只能阻止直接拆包，发布说明仅陈述该范围，不宣称不可提取。

## M4 资源版本发布准备

核对样本与依赖许可、确定项目开源许可证，准备格式版本、支持矩阵、配置样例、迁移、回滚、签名与故障说明。保护机制和评测源码均纳入开源规划，实际密钥和游戏资产按授权管理。

退出条件：版本产物可追踪到设计、实现、样本和报告；失败案例有处理结论；正常安装和启动透明。当前没有自动发布仓库、签署许可证或对外提交的动作。

## v0.2 关键数据阶段

资源链条通过后，从主线程普通类内少量非序列化整数开始。先设计受保护表示、读取校验、错误处置和透明接入，之后实施构建适配。

使用同一功能样本分别测试精确与变化搜索、写入、冻结、旧值重放和定向绕过。检测、使用前拒绝和最终作弊收益分开记录。通过后再讨论其他数据类型与访问模式。

## 实施时的建议结构

- packages/com.kingsjoys.kingssafe：Editor 构建接入与必要 Runtime，程序集分离。
- src/KingsSafe.Core 与 src/KingsSafe.Cli：资源格式、构建保护与工具入口。
- samples/UnityClient：固定版本研究样本及资源。
- benchmarks：任务定义、验证器、性能与攻防适配。
- tests：格式、认证、引用与生命周期回归。
- configs 与 docs：配置、设计、决策和发布说明。

上述代码目录尚未创建。评测产物、私有映射、游戏密钥、签名私钥和真实凭证不直接提交公共仓库。实现排期在环境和实验范围明确后制定。
